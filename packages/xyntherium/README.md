# xyntherium

`npx xyntherium …` is the Verify Gate CLI, [`@xyntherium/verify-cli`](../verify-cli), under a short name.

```bash
npx xyntherium init --policy-gate   # draft document change tests from your policy and help docs (draft: review before trusting)
npx xyntherium run                  # run the Gate locally; a changed policy prints "Policy changed: N answers need review"
```

Evidence support for supplied sources only; not a compliance certification, legal assessment, or determination of real-world truth. MIT.
